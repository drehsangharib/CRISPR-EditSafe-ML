# Scientific Report Template

## Objective
Develop and validate a reproducible computational workflow for CRISPR off-target risk prediction.

## Dataset provenance
Describe public dataset source, assay type, accession, preprocessing, and inclusion/exclusion criteria.

## Methods
Describe feature engineering, model families, validation strategy, class imbalance handling, and calibration.

## Results
Report AUPRC, AUROC, recall, precision, top-k ranking performance, and error analysis.

## Interpretation
Discuss mismatch-position effects, seed region effects, and high-risk candidate ranking.

## Limitations
State limitations clearly, including assay bias, data imbalance, and lack of clinical validation.

## Reproducibility
Include environment file, Docker image, tests, exact commands, and random seeds.
